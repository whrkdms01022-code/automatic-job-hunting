# 면접 답변 채점 기준 — 4단 액션 구조 (100점, 70점 컷)

출처: 구독편 #5. `interview-coach` 스킬이 답변을 채점할 때 이 기준을 쓴다.

## 채점 축 4개 (각 25점, 합계 100점)

| 축 | 25점 기준 | 낮은 점수 |
|---|---|---|
| 지표 (Metric) | 구체 KPI 명시 (월 매출, 전환율, 이탈률 등) | 무엇을 측정했는지 불명확 |
| 값 (Value) | before/after 수치가 명확 | 수치 없이 "많이/크게" 류 표현 |
| 근거 (Rationale) | 본인이 한 구체적 행동 + 왜 그렇게 했는지 판단 근거 | "담당했습니다" 같은 책임 나열 |
| 결과 (Result) | 행동이 지표에 미친 인과가 명확 | 결과가 있지도, 인과가 불분명 |

70점 이상 → 통과. 미만 → "어디가 부족한지 + 수정 방향" 피드백 후 재답변 요청.
첫 답변에서 70점 넘기는 경우는 보통 30% 정도. 대부분 "값 없음" 또는 "근거 약함"에서
감점된다. 2회 루프 돌면 80점 이상 나오는 게 일반적.

## 예시

일반론: "불량률 개선에 기여했습니다." (지표/값/근거/결과 전부 불명확 → 낮은 점수)

4단 액션: "월 불량률이 3.2%에서 1.1%로 줄었는데(지표+값), 공정별 검사 기준을
표준화하고 치명결함 항목에 전수검사를 도입한 게(근거) 재발률을 낮춘 결과입니다(결과)."

## 이력 검증 5항목 — 예상질문 뽑기 전에 먼저 확인

자소서에 쓴 내용이 실제로 방어 가능한지 먼저 점검한다. 이걸 건너뛰면 면접장에서
"그거 정말 본인이 한 건가요?" 같은 질문에 버벅인다.

1. 직무 레벨 매칭 — JD가 요구하는 레벨과 실제 경험 깊이가 맞는가
2. 역할 범위 — 팀 성과를 본인 성과처럼 과장하지 않았는가
3. 기술/도구 숙련도 — "활용했다"고 쓴 것을 실제로 설명할 수 있는가
4. 수치 근거 — 자소서의 수치를 "어떻게 측정했는지" 답할 수 있는가
5. 시점/기간 — 경험 시점과 기간이 이력서와 모순되지 않는가

리스크가 나오면 방어 답변을 미리 준비: 인정("직접 한 건 아닙니다") → 사실 교정("실제로는
~역할이었습니다") → 강점 재프레이밍("그 덕분에 ~을 배웠습니다") 순서로.

## 예상질문 생성 절차

1. 사용자의 자소서(`자소서-시스템/` 또는 제출한 자소서 파일)와 JD를 읽는다.
2. JD에서 3번 이상 반복되는 키워드/역량을 뽑고 "필수"와 "우대"를 구분한다.
3. 위 이력 검증 5항목을 먼저 훑어 리스크가 있으면 사용자에게 알린다.
4. "역량 × 경험 교차" 방식으로 질문을 만든다 — JD가 원하는 역량과 자소서에서 검증이
   필요한 경험 포인트를 교차시켜서 인성 질문 10개 + 직무 질문 10개를 만든다.
   일반론("협업 경험을 말해보세요") 금지 — 자소서 문장을 인용해 "왜", "어떻게"를 파고드는 질문.
   각 질문 옆에 "검증 포인트" (이 질문이 뭘 보려는 건지)를 괄호로 표시한다.
5. 사용자가 질문 하나를 골라 답변을 타이핑하면 위 4단 채점(각 25점)을 적용한다.
6. 70점 미만이면 피드백 후 재답변을 요청하는 루프를 돈다 (보통 2회면 80점대 도달).
7. 면접 전날엔 압박질문도 준비: 자소서에서 "과장 가능성이 있는 부분" 3개를 추출해
   면접관이 파고들 수 있는 질문 + 방어 방향을 정리한다 (전부 연습할 필요 없이, 방향만 숙지).

## 면접 후 복기 (면접 끝나고 1시간 이내)

1. 회사명, 면접 유형(인성/직무/임원)을 받는다.
2. 실제로 받은 질문 중 기억나는 것을 전부 적게 한다.
3. 잘 답변한 것 / 못 답변한 것을 구분한다.
4. 결과를 면접 복기 파일로 `면접-지식베이스/`에 카드로 저장할지 물어본다 (`interview-kb` 연결).
5. 같은 회사 2차 면접이 있으면, 1차 복기를 다시 입력으로 넣어서 1차에서 약했던 부분을
   집중적으로 다시 질문 생성한다.

## 출력 형식

- 예상질문은 인성/직무로 나눠 번호 매겨서 제시, 각 질문 옆에 어느 자소서 문장/JD 키워드에서
  파생됐는지 괄호로 표시.
- 답변 채점은 4축 점수 + "빠진 것 / 고칠 것 / 잘한 것" 세 줄로 짧게, 모호한 칭찬 없이.
