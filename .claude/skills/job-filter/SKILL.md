# 공고 1차 필터 + 트래커 입력

목표: 사용자가 붙여넣은 공고 알림 메일 본문, 공고 URL, 또는 공고 목록을
`채용-트래커/트래커.md`의 필터 기준(직무/지역/경력/제외 키워드)으로 걸러서,
통과한 공고만 진입난이도 태그와 함께 트래커 표에 새 행으로 추가한다.

## 입력이 없으면 먼저 물어볼 것

1. 공고 알림 메일 본문(복붙), 공고 URL 목록, 또는 공고 목록 텍스트
   (사람인/잡코리아/원티드/자소설닷컴 무엇이든, 커뮤니티에서 긁어온 목록도 가능)
2. `채용-트래커/트래커.md`의 필터 기준이 비어 있으면 (직무/지역/경력) 먼저 채워달라고 요청

## 절차

1. `채용-트래커/트래커.md`를 읽어 필터 기준, 우선순위, 제외 키워드를 확인한다.
2. 입력에서 회사명, 직무명, 마감일, 공고 링크(또는 식별자)를 추출한다.
   - 메일 타이틀만으로 지역을 판단하지 않는다. 타이틀에 지역이 안 나오는 경우가 많다 —
     공고 URL이 있으면 WebFetch로 열어서 지역을 재확인한 뒤에만 통과시킨다.
3. 다음 기준으로 필터링한다:
   - 직무명이 트래커 기준과 일치/유사한가
   - 지역이 기준 지역(예: 서울/판교)에 포함되는가
   - 경력 조건이 맞는가
   - 제외 키워드(코딩테스트 필수/교대근무/인턴 등)가 공고 내용에 있는가 — 있으면 탈락
4. 통과한 공고에 우선순위를 매긴다: 트래커의 "우선순위" 목록(예: 1순위 직무군)에
   해당하면 ⭐, 조건부로 볼만하면 🔵.
5. 대기업/인기 기업 공고는 진입난이도 태그를 붙인다:
   - `[진입↑]` 직무 자체의 진입장벽이 낮은 직무 (예: IT기획, QA, 기술영업 — 기술 이해도가
     차별점이 되는 직무)
   - `[진입→]` 해볼 만함
   - `[진입↓]` 서류 통과가 어려움 (코테+학력 필터가 강한 개발 직군 등)
   이 판단이 애매하면 태그 없이 두고 사용자에게 맡긴다.
6. 통과한 공고만 트래커 표에 `상태: 신규`로, 우선순위/진입난이도 태그와 함께 새 행을 추가한다.
   탈락한 공고는 왜 탈락했는지 한 줄씩 요약해서 보여주되 트래커에는 넣지 않는다.
7. 마지막에 "N건 중 M건 통과" 요약을 준다.

## 주의

- 애매한 경우(직무명이 비슷하지만 확신이 안 서는 경우)는 임의로 걸러내지 말고 사용자에게 물어본다.
- 이미 트래커에 있는 회사+직무 조합은 중복 추가하지 않는다.
- 여러 플랫폼(사람인/잡코리아/원티드/자소설닷컴)에서 같은 공고가 중복으로 들어올 수 있다 —
  회사명+직무명이 같으면 플랫폼이 달라도 중복으로 처리한다.
