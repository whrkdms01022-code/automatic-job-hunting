# 링크드인 프로필 세팅

목표: 사용자의 이력서/포트폴리오 내용을 받아 `링크드인-시스템/프로필-가이드.md`의 절차를
따라 채용담당자 검색에 걸리는 프로필 초안을 만든다.

## 입력이 없으면 먼저 물어볼 것

1. 이력서 텍스트 또는 파일, 포트폴리오/블로그 링크
2. 타겟 직무명 (여러 개면 우선순위 1개)

## 절차

`링크드인-시스템/프로필-가이드.md`를 읽고 그 순서대로 아래를 전부 만든다.

1. 타겟 직무 기준 검색 키워드 8개 추출 (직무명 → 핵심 툴/방법론 → 산업 도메인 순)
2. 헤드라인 후보 3개 (220자 이내, 키워드 + 임팩트)
3. About 섹션 (2,600자 이내, 4단 구조: 훅 1줄 / 핵심역량 3줄 / 대표성과 2개(숫자 필수) / CTA)
4. 경력 bullet을 [행동 → 수치 결과] 구조로 재작성 (원문에 수치가 없으면 사용자에게 물어봐서 채운다 — 지어내지 않는다)
5. 대표 프로젝트 상위 3개 선정 및 한 줄 요약
6. 스킬 섹션 순서 (타겟 직무 기준 재정렬)

## 출력 형식

각 섹션을 그대로 복붙할 수 있게 코드블록으로 준다. 마지막에 가이드 문서의 체크리스트를
확인시킨다 (이력서 공개 설정, 키워드 자연스러움, 숫자 누락 여부).

## 주의

- 성과에 숫자가 없으면 만들어내지 말고 사용자에게 실제 수치를 물어본다.
- 원문에 없는 경험을 추가하지 않는다 — 표현만 재구성한다.
