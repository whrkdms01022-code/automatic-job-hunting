# 면접 지식베이스 — 카드 추가 / 검색

목표: `면접-지식베이스/00-INDEX.md`의 표준 포맷을 따라 카드를 추가하거나,
JD 키워드로 관련 카드를 찾아서 회사별 면접 준비를 30분 내로 끝나게 돕는다.

## 모드 1: 카드 추가

입력: 면접에서 나온 질문, 그때 한 답변(또는 더 다듬은 모범답변)

1. `00-INDEX.md`의 카드 표준 포맷(30초/2분/10분)을 확인한다.
2. 어느 폴더(01-경험-스토리 ~ 05-최신-리서치)에 속하는지 판단한다.
3. 기존에 비슷한 카드가 있는지 먼저 찾는다 — 있으면 새 카드를 만들지 말고 기존 카드를
   갱신한다 (버전이 쌓일수록 답변이 다듬어지는 게 이 시스템의 핵심).
4. 없으면 표준 포맷으로 새 카드를 만들고, `00-INDEX.md`의 카드 목록 표에 한 줄 추가한다
   (카드명, 폴더, 최근 갱신일).

## 모드 2: 회사별 준비 카드 검색

입력: JD 텍스트 또는 회사/직무명

1. JD에서 핵심 키워드(기술/방법론/도메인)를 뽑는다.
2. `00-INDEX.md` 카드 목록과 각 폴더를 훑어서 관련 카드를 찾는다.
3. 찾은 카드 목록을 링크(파일 경로)로 제시한다 — 내용을 복사해서 보여주지 않는다,
   원본 갱신 시 항상 최신본을 보게 하기 위함.
4. 관련 카드가 없는 영역이 있으면 "이 부분은 새 카드가 필요함"이라고 짚어준다.

## 주의

- 카드 내용을 다른 파일에 복사-붙여넣기 하지 않는다. 항상 파일 경로로 링크한다.
- 카드를 갱신할 때는 "최근 갱신" 날짜를 오늘 날짜로 바꾼다.
