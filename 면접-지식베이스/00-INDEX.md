# 면접 지식베이스 INDEX

카드 단위로 쌓이는 면접 지식. 회사별 면접 준비 파일에는 카드 내용을 복사하지 않고
**링크만 건다** — 원본 1개만 고치면 전체가 갱신되도록.

## 폴더 구조

```
01-경험-스토리/       프로젝트/경험별 답변 (STAR + 4단 액션)
02-기술-용어사전/     자주 나오는 기술/개념 질문
03-설계-케이스/       시스템/프로세스 설계 질문
04-더-나은-설계/      "다시 한다면 어떻게?" 회고형 질문
05-최신-리서치/       최신 트렌드/이슈 질문
```

## 카드 표준 포맷

카드 1장은 30초 / 2분 / 10분, 3단 깊이로 작성한다. 면접에서 "간단히"면 30초,
"좀 더 자세히"면 2분, "설계까지"면 10분 버전을 꺼낸다.

```markdown
# 카드 제목

## 30초 버전
(결론 + 핵심 수치 한 문장)

## 2분 버전
(왜 그렇게 했는지, 주요 의사결정 2~3개)

## 10분 버전
(전체 과정, 트레이드오프, 평가/검증 방법)

## 출처
- 회사: (이 답변이 나온/쓰인 면접)
- 최근 갱신: YYYY-MM-DD
```

## 카드 목록

(면접을 볼 때마다 여기에 새 카드를 추가한다)

| 카드 | 폴더 | 최근 갱신 |
|---|---|---|
| (예시) 불량률 개선 프로젝트 | 01-경험-스토리 | - |

## 회사별 면접 준비 흐름 (지식베이스가 쌓인 이후)

1. JD 읽기 (10분)
2. JD 키워드 기반으로 이 INDEX에서 관련 카드 추출 (2분)
3. 이 회사 맥락에 맞게 카드 강조점만 조정 (20분)
4. 없는 카드만 새로 작성

새로 만들 카드가 없으면 30분 내로 끝난다.
