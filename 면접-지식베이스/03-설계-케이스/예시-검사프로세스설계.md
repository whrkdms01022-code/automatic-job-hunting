# 신규 라인 검사 프로세스 설계 (예시 카드)

## 30초 버전
불량 유형별 위험도를 기준으로 전수/샘플링 검사를 나누고, 치명결함은 전수,
경결함은 AQL 기반 샘플링으로 설계하는 방식을 제안합니다.

## 2분 버전
- 위험도 분류 기준 (치명/중/경결함)
- 검사 방식 선택 근거 (전수 vs 샘플링, 비용-리스크 트레이드오프)
- 검사 데이터 피드백 루프 (SPC 관리도로 공정 이상 조기 탐지)

## 10분 버전
(실제로 설계해본 경험이 있다면 구체적 수치와 함께. 없다면 가상 시나리오로
전체 아키텍처, 예외 처리, 검증 방법까지 확장해서 준비)
