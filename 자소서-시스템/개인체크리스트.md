# 개인 체크리스트 (88점 달성 후 최종 확인용)

88점을 넘긴 뒤에만 순서대로 확인. 이 체크리스트는 점수에는 안 잡히지만 제출 전
마지막으로 걸러야 하는 개인 취향/실수 항목.

- [ ] 가운뎃점(·) 사용 안 함 — 대신 쉼표나 문장 분리
- [ ] "~할 수 있습니다" → "~하도록 하겠습니다" 류 상투구 재확인 (기준표에서 걸렀어도 재검)
- [ ] 회사명·직무명 오탈자 없음 (다른 회사 자소서 재활용 흔적 없음)
- [ ] 글자수 제한 준수 (공고 명시 글자수의 95~100%)
- [ ] 문단 수 3~5개, 첫 문단에 결론 배치
- [ ] 숫자 단위 표기 일관성 (%, 건, 원 등)
- [ ] 마지막으로 소리 내어 1회 읽기 — 어색한 연결 문장 확인

전부 체크되면 제출 가능.
