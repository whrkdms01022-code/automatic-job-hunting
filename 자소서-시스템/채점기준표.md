# 자소서 채점기준표 (100점 만점, 통과선 88점)

출처: 구독편 #2-B 실제 배점 + 자소서 프롬프트 완전판 v2. QA/QC 기본값이지만
"직무 연관성" 항목의 예시만 바꾸면 어느 직무에도 적용 가능.

## 감점 항목

| 항목 | 감점 | 기준 |
|---|---|---|
| 두괄식 아님 | -10 | 문단 첫 문장에 핵심 결론이 없음 |
| 수치 없는 결과 | -8 | 성과를 수치/지표 없이 서술 |
| 경어체 남용 | -5 | "~하였습니다" 식 상투적 경어체 반복 |
| 직무 연관성 낮은 경험 | -10 | 공고 요구역량과 무관한 경험을 메인으로 씀 |
| AI 문장 냄새 | -7 | 과도한 존댓말, 클리셰, 아래 "AI 유사성 체크리스트" 패턴 |
| 수동적 단어 반복 | -5 | 관리/수행/참여/파악/이해/보고/처리/전공 등 반복 |

## 가점 항목

| 항목 | 가점 | 기준 |
|---|---|---|
| 수치로 증명된 결과 | +10 | before/after 수치가 명확 |
| 직무 키워드 자연스럽게 포함 | +8 | 역량 키워드를 나열이 아니라 경험 속에 녹임 |
| 구체적 상황 묘사 | +5 | 상황(S)이 추상적이지 않고 구체적 |
| 판단 근거 명시 | +7 | "왜 그 방법을 선택했는지"가 드러남 |

88점이 통과선인 이유: 90점은 도달 비용 대비 효용이 낮고, 85점은 아직 구멍이 보임.
88점은 "한두 문장만 고치면 제출 가능한 상태"의 마지노선.

## 단어 선택 규칙 (은근 제일 중요)

**수동적 단어 — 최대한 피하기**: 또한, 관리, 지원, 수행, 보고, 파악, 이해, 도움, 처리, 참여, 전공
→ "~을 관리했다/수행했다/참여했다"는 주체성이 사라지고 "시킨 일 했네" 인상을 줌.

**능동적 단어 — 적극 사용**
- 문제 해결 중심: 문제, 인식, 개선, 해결, 도출, 성과, 협업, 효율
- 데이터 기반: 데이터, 정보, 기반, 분석, 활용, 구축

**Before/After**
- ✕ "프로젝트에 참여해 데이터를 관리하고 보고서를 수행했다"
- ✓ "데이터 품질 문제를 인식해 분류 체계를 개선하고, 재현율 15% 향상 성과를 도출했다"

## 글쓰기 3대 원칙

1. **경험을 나열하지 말고 구조화**: 경험 A, B, C를 콤마로 잇지 말고 인식→판단→실행→결과 흐름으로 엮는다.
2. **결과보다 판단 과정을 드러낸다**: "~했다"보다 "왜 그 방법을 선택했는지"가 먼저.
   - ✕ "Hybrid Retrieval을 적용했고" / ✓ "누락 원인이 검색 정확도에 있다고 판단해 Hybrid Retrieval을 적용했고"
3. **활동 나열이 아니라 문제-해결 흐름 설계**: 문제↔솔루션 1:1 대응으로 쓴다.
   - ✕ "A로 ~하고, B로 ~하고, C로 ~했다" / ✓ "문제1은 A로 해결하고, 문제2는 B로 막았으며..."

## 구조 전략 (문항 유형별로 선택)

- **KKK+STAR** (기본): 1K 두괄식 결론 1문장 → 2K STAR(S 2~3줄, T, A는 가장 상세히, R은 수치 필수) → 3K 성장가능성+발휘방안
- **STAR-F**: STAR 뒤에 "이 경험을 지원 직무에서 어떻게 활용할지" 미래형으로 추가. 직무역량 문항에 효과적.
- **3C4P**: 3C(고객/회사/경쟁사)로 배경 짧게 → 4P로 성과 집중. 글자수 적으면 3C 생략하고 4P에 80%.
- **두괄식+스토리텔링**: 서론 두괄식 1문장 → 본론 스토리텔링 → 결론 다시 두괄식으로 직무 연결.

문항 유형 매칭: 직무역량→KKK+STAR/STAR-F, 프로젝트경험→STAR/3C4P(행동에 가장 많은 분량),
가치관/장단점→두괄식+스토리텔링, 지원동기→KKK(기업이해→접점→기여의지), 포부→단기/중기 목표.

## 시제 규칙

경험/사실 → 과거형 · 준비 과정 → 과거형 · 현재까지 유지되는 상태 → 현재형 · 입사 후 기여/다짐 → 미래형

## AI 유사성 제거 체크리스트 (2개 이상 해당되면 수정 필요)

**표현 패턴**
- "~이 아니라 ~" 대조 구문: 한 문항에 2회 이상 금지
- "N개 축으로 나눠 접근": 전체 자소서에서 1회만 허용
- "~가 아니라" 표현: 최대한 완화, 긍정형으로

**구조 패턴**
- "기여하겠습니다" 등 마무리 표현이 문항마다 반복되면 변주
- "~했습니다" 4문장 이상 연속 금지 — 종결어미 변주
- 문항 4개가 모두 같은 리듬이면 1~2개는 톤 변경

**인간미 패턴**
- 감정/생각이 전혀 없으면 안 됨 — 각 문항에 최소 1곳 "꽤 답답했고", "이대로는 안 되겠다 싶었다" 같은 당시 심정/판단 동기 한 줄

## 최종 체크리스트 (88점 달성 후)

- [ ] 글자수 범위 준수 (95~100%)
- [ ] 가운뎃점(·) 0개
- [ ] AI 유사성 체크리스트 전체 통과
- [ ] 각 문항에 발휘방안/미래 연결 포함
- [ ] JD 역량 매칭 테이블 커버리지 100%
- [ ] 블라인드 채용 시 학교/학과명 익명화
- [ ] 시제 규칙 준수
- [ ] 경험 간 자연스러운 연결 (나열 금지)
- [ ] 성과에 수치/지표 포함
- [ ] 수동적 단어 최소화, 능동적 단어 사용

## 채점 시 감점 표기 규칙

총점만 주지 말고 "42점. 두괄식 아님 -10, AI냄새 3건 -7, 직무연관성 낮음 -10, 수치없음 -8"
형태로 항목별 감점 사유를 반드시 병기한다. "전반적으로 잘 작성됨" 같은 모호한 총평 금지.
